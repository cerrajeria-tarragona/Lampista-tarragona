# Lampista Tarragona — web estática SEO

Web lista para GitHub Pages en `https://github.com/cerrajeria-tarragona/Lampista-tarragona`.

## Publicación

1. Descomprime el ZIP. **Sube el contenido interior**, no la carpeta contenedora, a la raíz de la rama `main`.
2. En GitHub abre **Settings → Pages → Build and deployment**.
3. Selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**. Pulsa **Save**.
4. La URL prevista es `https://cerrajeria-tarragona.github.io/Lampista-tarragona/`.
5. Comprueba que la web y las páginas interiores cargan con colores, imágenes y botones.
6. En Google Search Console envía `https://cerrajeria-tarragona.github.io/Lampista-tarragona/sitemap.xml`.

- Añade los datos comerciales y legales aplicables (identificación del prestador, política de privacidad si incorporas formularios, etc.).
- Si cambias el nombre del repositorio o usas un dominio propio, actualiza las URL de `sitemap.xml`, `robots.txt` y etiquetas canonical de los HTML.

No requiere npm, PHP ni base de datos. CSS e ilustraciones SVG están incluidos localmente.
